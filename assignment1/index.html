1. Problem Statement

The goal is to compare neural network architectures (Linear, MLP, CNN, LSTM/GRU, Transformer) on Fashion-MNIST classification and understand how each architectural choice affects performance. Some classes like Trouser or Bag are easy to separate by shape alone, while Shirt/Pullover/Coat/T-shirt share similar silhouettes and need the model to learn texture features — making this a useful benchmark for comparing model capacity.

2. Dataset and EDA

Dataset: Fashion-MNIST (Xiao et al., 2017) — 70,000 grayscale 28×28 images, 10 classes. Full EDA: notebooks/eda.ipynb (executed, outputs saved).

3. What We Did for M1

  • Data pipeline (src/data/dataset.py) — stratified 90/10 split, seed 42, normalisation, DataLoaders.
  • Training engine (src/engine/trainer.py) — train/val loop, early stopping (patience 5), checkpoint on best val macro-F1.
  • Linear classifier (src/models/linear.py) — 784 → 10, 7,850 params.
  • MLP (src/models/mlp.py) — 784 → 256 → 10, ReLU, dropout 0.2, 203,530 params.
  • Utils: metrics.py (accuracy, macro-F1), plots.py (curves, confusion matrix, sample grids), seed.py.
  • Scripts: train.py and eval.py.

CNN, LSTM/GRU, Transformer — in repo but empty, part of M2 Final.
